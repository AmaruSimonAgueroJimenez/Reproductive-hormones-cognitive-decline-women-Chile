```{python}
#| label: rebuild-public-administrative-evidence

from pathlib import Path
import sys, contextlib, io, json, html, base64
from IPython.display import display, Markdown, HTML
PROJECT = next(p for p in [Path.cwd(), *Path.cwd().parents] if (p/'scripts/access_extension/access_report.py').exists())
sys.path.insert(0, str(PROJECT/'scripts/access_extension'))
import access_report as report
# Public aggregate mode regenerates every display and refits the facility models.
# Original-record refresh is a separate documented command requiring the data volume.
with contextlib.redirect_stdout(io.StringIO()):
    evidence = report.rebuild_public()
def section(kind, index):
    for p in evidence[kind][index]['paragraphs']: display(Markdown(p))
def table(index):
    t=evidence['tables'][index]
    import pandas as pd
    frame=pd.DataFrame(t['rows'], columns=t['columns'])
    display(HTML('<div class="table-responsive">'+frame.to_html(index=False,escape=True)+'</div><p class="table-note">'+html.escape(t['note'])+'</p>'))
    display(Markdown('[Download source table](../'+t['csv_path']+')'))
def figure(index):
    f=evidence['figures'][index]
    uri='data:image/png;base64,'+base64.b64encode((PROJECT/f['path']).read_bytes()).decode()
    display(HTML('<img class="paper-figure" src="'+uri+'" alt="'+html.escape(f['alt'],quote=True)+'" style="max-width:100%;height:auto"><p class="figure-caption">'+html.escape('Figure '+str(f['number'])+'. '+f['caption'])+'</p>'))
    base=str(Path(f['path']).with_suffix(''))
    display(Markdown('[Editable SVG](../'+base+'.svg) · [Vector PDF](../'+base+'.pdf) · [600 dpi PNG](../'+base+'.png)'))
```

### Reproducing the instrument analyses

The instrument figures, table cells and scientific Methods and Results text are
shared with the Word reports. This page verifies the saved evidence files and
recalculates the explicitly declared aggregate checks at render time. Source
record extraction and original analytical processing are separate operations;
they are not silently repeated when a reader renders this page. The aggregate
inputs and analysis code allow the instrument outputs to be reconstructed
without the external data volume. Original-source refresh additionally requires
the same authorised REM releases and annual coded templates.

The commands below are displayed for inspection and are not executed during
rendering. Use the scientific and document environments recorded by the runner.

```{python}
#| label: ni-instrument-explicit-rebuild-commands
```

## Computational reproducibility

The default executable path uses saved public aggregate inputs and refits the facility models. It regenerates every reported table and figure. Original person-level hospital records and encrypted identifiers stay on the external data volume and are not included in this report or the downloadable package. The separate raw-refresh mode re-extracts source files and reproduces the public aggregate inputs; access to the same raw releases and the stated external data tree is required.

From the project root, use the Python environment recorded in the software manifest:

```{.bash}
python3 scripts/run_access_diagnostic_extension.py --html
# Rebuild the matching Word document as well
python3 scripts/run_access_diagnostic_extension.py --word --html
# Refresh original records only when the external data volume is available
python3 scripts/run_access_diagnostic_extension.py --refresh-raw --word --html
```

The raw path additionally uses the pre-existing FONASA denominator and public facility/context preparation described in the build instructions. Source hashes, dictionary mappings, denominator checks, duplicate decisions, coding exclusions and exact reporting eligibility remain inspectable. Public aggregation and raw-source refresh provide different reproducibility levels; independent replication requires obtaining the original releases rather than accepting derived data as their own validation.
